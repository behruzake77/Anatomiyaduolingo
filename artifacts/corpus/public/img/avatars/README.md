# CORPUS avatar assets

These SVG avatars are local, versioned copies generated from the open-source [DiceBear Avatar Library](https://www.dicebear.com/) through its [HTTP API](https://www.dicebear.com/integrations/http-api/). Local copies are used so avatar selection does not depend on a third-party request at runtime.

The DiceBear project and individual styles have their own license and attribution terms. See the authoritative [DiceBear licenses page](https://www.dicebear.com/licenses/) before redistributing or changing these assets.
